# Dexter3

A simple Flask web application that demonstrates basic web development with Python.

## Features

- Displays a welcome message and current time
- Serves a simple HTML page
- Runs on port 5001 with debug mode enabled
- Easy to modify and extend

## Prerequisites

- Python 3.x
- pip (Python package installer)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sumitkumarbittu/Dexter3.git
   cd Dexter3
   ```

2. Install the required packages:
   ```bash
   pip install flask
   ```

## Running the Application

1. Start the Flask development server:
   ```bash
   python app.py
   ```

2. Open your web browser and navigate to:
   ```
   http://localhost:5001
   ```

## Project Structure

- `app.py` - Main application file containing the Flask app and routes
- `README.md` - This file, containing project documentation

## Customization

You can modify the HTML content in `app.py` to change what's displayed on the webpage. The application is set up with debug mode enabled, so changes will be automatically reloaded when you save the file.
